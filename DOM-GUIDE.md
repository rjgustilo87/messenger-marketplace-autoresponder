# Messenger DOM Structure Documentation

## Overview

This document details the DOM structure of Facebook Messenger (messenger.com) for automation purposes.

**Last Updated:** 2026-02-19

**Important:** Facebook frequently updates their UI. The selectors documented here may change. Always check `dom-structure.json` generated at runtime for the most current information.

---

## Login Page Structure

When not logged in, messenger.com redirects to a login page.

### Key Selectors

| Element | Selectors | Notes |
|---------|-----------|-------|
| Email Input | `input[type="email"]`, `input[name="email"]`, `#email` | Primary login field |
| Password Input | `input[type="password"]`, `input[name="pass"]`, `#pass` | Password field |
| Login Button | `button[type="submit"]`, `button[name="login"]` | Submit login |

### Detection
```javascript
const isLoginPage = await page.$('input[name="email"]') !== null;
```

## Conversation List (Sidebar)

The left sidebar contains the list of conversations.

### Container Selectors

```javascript
const containerSelectors = [
  '[role="navigation"]',           // ARIA navigation role
  '[data-testid="mw_conversations_list"]', // Facebook test ID
  '[aria-label="Chats"]'           // ARIA label
];
```

### Individual Conversation Items

```javascript
const conversationSelectors = [
  '[role="listitem"]',                    // ARIA listitem
  '[data-testid="mw_conversation_list_item"]', // Facebook test ID
  'a[href*="/t/"]',                        // Link to conversation thread
  'div[role="listitem"]'                    // Div with listitem role
];
```

### Conversation Item Structure

Each conversation item typically contains:

```html
<div role="listitem">
  <!-- Profile picture -->
  <img src="..." alt="">
  
  <!-- Conversation info -->
  <div>
    <!-- Name -->
    <span>Contact Name</span>
    
    <!-- Last message preview -->
    <span>You: Hello!</span>
    
    <!-- Timestamp -->
    <span>2h</span>
  </div>
  
  <!-- Unread indicator (if present) -->
  <span aria-label="1 unread"></span>
</div>
```

### Unread Detection

```javascript
const unreadSelectors = [
  '[aria-label*="unread"]',      // Contains "unread"
  '[aria-label*="Unread"]',      // Contains "Unread"
  '.x6s0dn4.x78zum5'             // FB class pattern (changes often)
];
```

## Conversation Detail View

The main area showing the active conversation.

### Container

```javascript
const mainContainer = [
  '[role="main"]',                    // ARIA main role
  '[data-testid="message_container"]',
  '[aria-label*="Conversation"]'
];
```

### Message Bubbles

**Outgoing (sent by you):**
```javascript
'[data-testid="outgoing_message"]'
'.x1yc5d2u.xqmdsaz'  // Class pattern
```

**Incoming (received):**
```javascript
'[data-testid="incoming_message"]'
'.x1yc5d2u:not(.xqmdsaz)'
```

## Message Input

The text input area at the bottom of the conversation.

### Input Field Selectors

```javascript
const inputSelectors = [
  '[role="textbox"]',           // ARIA textbox role
  '[contenteditable="true"]',   // Contenteditable div
  '[data-testid="mw_text_input"]',
  '[aria-label*="message"]',    // Contains "message"
  '[placeholder*="message"]'
];
```

### Send Button

```javascript
const sendButtonSelectors = [
  '[aria-label="Send"]',
  '[data-testid="send_button"]'
];
```

### Sending Messages

```javascript
// 1. Click input to focus
await page.click('[role="textbox"]');

// 2. Type message
await page.keyboard.type('Your message here');

// 3. Press Enter to send
await page.keyboard.press('Enter');
```

## Marketplace Detection

### Text Indicators

Look for these keywords in conversation text:

- "Marketplace"
- "is interested in"
- "sent an offer"
- "asked about availability"
- "availability"
- "about your listing"
- "listing"
- "item"
- "price"

### ARIA Label Patterns

```javascript
const marketplacePatterns = [
  /marketplace/i,
  /interested/i,
  /offer/i,
  /availability/i
];
```

### Example Detection

```javascript
function isMarketplaceConversation(conversationText, ariaLabel) {
  const combined = (conversationText + ' ' + ariaLabel).toLowerCase();
  const indicators = [
    'marketplace',
    'is interested in',
    'sent an offer',
    'asked about'
  ];
  return indicators.some(ind => combined.includes(ind));
}
```

## CSS Classes Note

Facebook uses auto-generated CSS classes that change frequently. Classes starting with `x` (e.g., `x9f619`, `x1n2onr6`) are generated by their CSS-in-JS system and **should not be relied upon**.

**Prefer these instead:**
- `data-testid` attributes (more stable)
- ARIA roles (`role="listitem"`, `role="textbox"`)
- ARIA labels (`aria-label="Chats"`)
- Standard HTML attributes (`contenteditable`, `href` patterns)

## Common Issues & Solutions

### Selectors Not Working

1. **Check login status** - Many elements only appear when logged in
2. **Wait for load** - Use `page.waitForSelector()` before interacting
3. **Check for changes** - Facebook updates their UI frequently
4. **Use multiple selectors** - Try multiple selectors in order

### Rate Limiting

- Add delays between actions: `await page.waitForTimeout(1000)`
- Use realistic typing: `page.type(selector, text, { delay: 50 })`
- Limit messages per session
- Use non-headless mode (less detectable)

### Element Not Found

```javascript
// Try multiple selectors
async function findElement(selectors) {
  for (const selector of selectors) {
    const element = await page.$(selector);
    if (element) return element;
  }
  return null;
}
```
